
# Purchase Requisition System

## BACT7501 - Assessment 2
Software Development Project

## Project Description
This project develops a Purchase Requisition System using Python and Object-Oriented Programming (OOP). It builds on the programming logic developed in Assessment 1.

## Planned Features
- Enter staff details and purchase items.
- Calculate the total cost of requisitions.
- Automatically approve requisitions below $500.
- Allow managers to approve or not approve pending requests.
- Display all requisition details.
- Generate requisition statistics.
- Test the system using different scenarios.

## Development Approach
The system will use Python classes, objects, constructors, and methods. GitHub commits will track the development progress.

## Testing
At least five requisitions will be tested using different purchase amounts and approval decisions.
